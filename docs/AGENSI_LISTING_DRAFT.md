# Agensi listing package — prepared, not published

This file contains the final draft and operating checklist. Publication on
Agensi.ai is intentionally excluded from this release.

## Agent Monitor Free

**Short description:** Local dashboard for Claude Code, Codex, Cursor, Gemini
CLI, Copilot, OpenCode, Aider, and custom agents.

**Listing copy:** See every coding-agent session in one local dashboard. Track
working, waiting and idle states, tool activity, tests, conflicts, estimated
cost trends, Agent Health findings, and privacy-safe replay/export. Data stays
on the user's computer. The Free package is MIT licensed and does not require a
subscription.

**Price:** free.

**Package:** `agent-monitor-free-1.0.0-rc.1.zip`.

## Agent Monitor Pro

**Short description:** Signed CI audit policies and reproducible evidence for
teams using Agent Monitor.

**Listing copy:** Adds signed baselines, batch/CI policy checks and stable exit
codes to the complete MIT Free product. Offline Ed25519 licenses work without
telemetry; optional online activation sends only the license key and a random
installation UUID. No prompts, project names, paths or agent events leave the
machine.

**Proposed price:** US$49/year individual; US$199/year for up to 10 users.

**Package:** `agent-monitor-pro-1.0.0-rc.1.zip`.

## Payment and support decision

- For Brazil-first direct sales, Mercado Pago subscription plans are the
  preferred initial processor because they support BR, yearly recurrence, Pix,
  cards and boleto. Creating a seller account and accepting its final fees and
  terms remains a manual business action.
- Lemon Squeezy is the optional international merchant-of-record alternative;
  its tax handling and fees must be reviewed with a Brazilian accountant before
  activation.
- Support channel: repository issues for Free; private support email for Pro.
- Target response for Pro: two Brazilian business days.
- First-purchase refund window: 14 days, subject to applicable law and the final
  processor policy.
- Never request a license key in an issue, chat transcript, command argument or
  diagnostic export.

## Pre-publication human checklist

- [ ] Approve public product name, screenshots and final listing copy.
- [ ] Approve prices, currency, taxes, processor fees and refund terms.
- [ ] Create/verify the seller account and support email.
- [ ] Confirm ZIP checksums against the signed release record.
- [ ] Perform the deferred real Gemini permission test and update its claim.
- [ ] Publish Free, observe one clean installation, then publish Pro.

No checkbox above is performed automatically by the repositories or build
scripts. The two publication actions are outside the current scope.
